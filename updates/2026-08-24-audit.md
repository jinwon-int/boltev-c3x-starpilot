## 자동 업데이터 차단 결함

2026-07-04 수동 배포가 기기를 detached HEAD에 두었고 updater가 이를 target branch로 기억했다.

- `UpdaterTargetBranch=HEAD`
- `UpdaterFetchAvailable=1`
- `UpdateAvailable=0`
- 2026-08-24 03:24 KST `LastUpdateException`:

```text
git checkout --force --no-recurse-submodules -B HEAD FETCH_HEAD
fatal: 'HEAD' is not a valid branch name
```

`system/updated/updated.py`는 target branch로 `git checkout -B <branch> FETCH_HEAD`를 실행한다. `HEAD`는 브랜치 이름으로 쓸 수 없어 staging이 완료되지 않는다. target branch를 바꾸면 updater가 즉시 fetch/stage할 수 있으므로, 후보 SHA·백업·롤백·재부팅 창을 승인하기 전에는 수정하지 않는다.

## Bolt 2017 영향 분석

최신 소스는 우리 실기 fingerprint를 직접 포함한다.

- `CHEVROLET_BOLT_CC_2017`이 Bolt CC setpoint deadband 대상에 포함됨.
- 감속 버튼 직후 가속 버튼으로 방향을 바꿀 때 지속성을 확인하는 debounce 경로가 추가됨.
- upstream test matrix가 exact 2017 fingerprint의 작은 setpoint 오차 무시를 검사함.
- 공통 Bolt pedal-long test는 2017 fingerprint를 포함하고 새 longitudinal actuator delay `0.6`과 변경된 PID 값을 기대함. 실기 현재값은 `0.5` 및 이전 tuning 값이다.
- 새 stock-friction 실험은 `CHEVROLET_BOLT_ACC_2022_2023_PEDAL` 하나로 제한되어 우리 2017 non-ACC 차량에는 직접 적용되지 않음.
- 그 밖에 shared longitudinal/lateral control 코드가 크게 변경되어 단순 UI 업데이트로 취급할 수 없음.
